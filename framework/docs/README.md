# dot-js documentation

dot-js is a small, dependency-free front-end framework: describe user interfaces
with plain JavaScript, no build step required.

Read these in order if you're new:

1. [Architecture](./architecture.md) — how the pieces fit together and why.
2. [Installation](./installation.md) — get dot-js into a project.
3. [Getting Started](./getting-started.md) — build a tiny app in a few minutes.

Then dig into whichever feature you need:

- [Components](./components.md)
- [State management](./state.md)
- [Routing](./routing.md)
- [Event handling](./events.md)
- [DOM utilities](./dom.md)
- [HTTP client](./http.md)
- [Performance (list virtualization)](./performance.md)

Finally: [Best practices](./best-practices.md).

A complete working example (a ToDo app with a real backend) lives in `/example/todo-app`
in this repository, and uses every module listed above.
