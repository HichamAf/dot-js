# dot-js

A minimal, dependency-free front-end framework: describe user interfaces
with plain JavaScript. No build step, no other frameworks/libraries used
internally.

**Full documentation:** [`docs/README.md`](./docs/README.md) — architecture,
installation, a getting-started walkthrough, and a full guide to every
feature (components, state, routing, events, DOM, HTTP, performance).

```bash
npm install   # installs jsdom, a test-only dependency for DOM tests
npm test      # runs the framework's own unit tests (node:test)
```

See `/example/todo-app` in this repository for a complete application built
with dot-js.
