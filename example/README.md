# Example: ToDo app

`todo-app/` is a complete ToDo application built with the dot-js framework
(see `/framework`), proving out every feature it implements: components,
state, routing, events, DOM utilities, HTTP, and performance (list
virtualization).

See the repository root [`README.md`](../README.md) for setup instructions
and a feature-by-feature map of where each framework capability is used.
